# Directives

SOPs (Standard Operating Procedures) live here as Markdown files.

Each directive defines:
- **Goal** — What the task accomplishes
- **Inputs** — What's needed to start
- **Tools / Scripts** — Which execution scripts to call
- **Outputs** — Expected deliverables
- **Edge Cases** — Known gotchas and how to handle them

Directives are living documents — update them as you learn.
